# case07 square_dot 平方数点阵|离散单元累积

## 专题简介
正方形点阵，一行一列增加，点的总数快速累积。体会总量可以由一个个独立小单元累加得到。离散累加思想原型。

## 前置依赖
- 前置：case06 growth_compare
- 后续：case08 square_scale

## 学习目标
【基础目标】观察点阵行列增加，总点数如何增长。
【前瞻目标】离散的个体不断累加，形成一个总数量。

## 核心概念
1. 离散单元：一个一个独立小点
2. 离散累积：单元数量变多，整体总量同步上涨

## 可视化绘图要点
1. 多帧，点阵行列数逐步放大

## 教学提示
积分思想不只有图形面积，也可以是离散点、离散数目的累加。
