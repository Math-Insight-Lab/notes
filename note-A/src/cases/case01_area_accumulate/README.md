# case01 area_accumulate 矩形小块铺满|分割-累加（积分原型）

## 专题简介
把大图形切分成很多细小矩形单元，小块拼起来得到整体面积。建立"分割+累加"最基础直觉，是积分思想的原型。

## 前置依赖
- 前置：小学长方形面积基础
- 后续：case02 circle_split

## 学习目标
【基础目标】理解：大图形可以拆成很多小长方形，小块面积相加等于总面积。
【前瞻目标】感知：切分得越细小，小块拼出来的结果越贴近真实图形。

## 核心概念
1. 分割：把整体拆成很多小部分
2. 累加：把每一小块的大小全部相加，还原整体

## 可视化绘图要点
1. 多帧静态图：矩形不断切分得更细
2. 观察：方块变多、变小，铺满整个区域

## 教学提示
本案例只看图思考，不引入任何公式。为后续note-B、note-C积分做底层思维铺垫。
