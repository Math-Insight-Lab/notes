# case02 circle_split 圆分割拼接|化曲为直，逼近思想

## 专题简介
圆形不断等分切开，扇形碎片重新拼接，越来越接近长方形。体会"曲线可以用细小直边片段逼近"。

## 前置依赖
- 前置：case01 area_accumulate
- 后续：case03 irregular_grid

## 学习目标
【基础目标】看懂圆被切分之后重组的图形变化。
【前瞻目标】感知：分得越细，曲线图形可以越来越接近直边图形。

## 核心概念
1. 化曲为直：把曲线拆成大量细小片段
2. 逼近：细分份数越多，拼接结果越接近理想图形

## 可视化绘图要点
1. 左右双面板：左侧分割的圆，右侧拼接之后的近似图形
2. 多帧：分割份数不断增加，观察两侧变化

## 教学提示
只做直觉感知，不推导圆面积公式。为note-C曲边梯形逼近做思维铺垫。
