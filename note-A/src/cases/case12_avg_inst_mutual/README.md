# case12 avg_inst_mutual 平均-瞬时与互逆|微分积分来回转换

## 专题简介
运动场景下同时建立两套核心直觉：
1. 微分视角：取一小段时间，算平均速度；时间缩到很短，逼近瞬时速度（变化快慢）。
2. 积分视角：把每一小段时间走过的微小路程全部累加，得到总路程（累积总量）。

> 最重要的互逆感知：从路程可以得到速度；从速度累加又可以还原回总路程。小学只做看图直觉，不引入符号公式。

- 前置：case01 ~ case11
- 后续：note-B全套

## 学习目标
【基础目标】看懂：小段时间算平均；时间越短越接近一瞬间的快慢；小块路程相加得到总路程。
【前瞻目标】建立互逆直觉：**变化快慢（微分）和总量累积（积分）可以互相转换**，为note-C微积分基本定理FTC埋下朴素感知。

## 核心概念
1. 平均变化：一小段间隔之内的快慢。
2. 瞬时变化：间隔无限缩短之后得到一瞬间的快慢。
3. 累积：把无数小段微小结果相加，还原整体总量。
4. 互逆：总量求变化快慢；快慢做累加又回到总量。

## 可视化绘图要点
1. 双视图：
    - 左：路程-时间曲线，演示割线不断缩短，平均速度逼近瞬时速度（微分）。
    - 右：速度曲线，用小竖条表示每一小段的微小路程，不断累加得到总路程（积分）。
2. 多帧：时间间隔Δt不断缩小，同时观察两边的变化。
