# case06 polynomial_geom 多项式乘法几何拼图｜从整式到因式分解
## 专题简介
用矩形面积拼图理解多项式乘法 $(a+m)(b+n)$，从几何视角看待整式展开与因式分解。强化分割、局部求和、整体重组的思维。
## 前置依赖
- 前置学习：case05 negative_geom、case02 area_identity
- 后续依赖：case07 linear_system
## 学习目标
【基础目标】整式加减乘除运算、多项式因式分解基础方法，熟练图形与代数互化题型。
【前瞻目标】强化面积拆分、局部累加、整体重组思维，夯实积分「分割—近似—求和」的底层直觉。
## 核心概念
1. 矩形总面积 = 分割之后各个小矩形面积相加。
2. 多项式乘法：$(a+m)(b+n) = ab+an+mb+mn$。
3. 因式分解：把多项和变回几个因式相乘（图形合并变回拆分）。
## 可视化绘图要点
1. 大矩形拆分为4块小矩形，每一块对应一项代数式。
2. 在图中标注每一小块面积表达式。
3. 对比“相乘展开”和“因式分解”是图形的拆分与合并的互逆过程。
## 教学提示
重点：**整体 = 各部分之和**，这个思想是后续黎曼积分分割求和的底层思维原型。
