# case11 similar_triangle 相似三角形动态几何
## 专题简介
通过动态缩放演示相似三角形。理解图形缩放之后角度不变、边长成比例；巩固斜率、比例对应关系，建立局部图形近似等效思维。
## 前置依赖
- 前置学习：case10 quadratic_geom、case04 coord_walk
- 后续依赖：case12 circle_geom
## 学习目标
【基础目标】相似三角形判定、性质、比例计算、动态几何常规题型。
【前瞻目标】理解图形缩放比例不变性，巩固斜率、比例对应关系，感知局部图形近似等效思维。
## 核心概念
1. 相似三角形：对应角相等，对应边长成比例。
2. 缩放系数k：全部边长同时乘以k，角度保持不变。
3. 直角相似三角形直角边之比等价于直线斜率。
## 可视化绘图要点
1. 绘制原始直角三角形；再绘制缩放之后的相似三角形。
2. 多帧：展示不同缩放系数下的相似图形。
3. 标注对应边长比例，关联斜率概念。
## 教学提示
相似的比例不变思想，和后续极限“局部近似”可以打通：曲线很小局部可以近似看成为直线段（小直角三角形）。
