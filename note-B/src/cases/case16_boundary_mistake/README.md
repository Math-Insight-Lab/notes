# case16 boundary_mistake 初中常见概念易错边界合集【重构三大分类·适配极限学习】
## 专题简介
摒弃零散错题堆砌，按照微积分前置认知重新组织。扫清初中核心概念漏洞，同时专门辨析「趋近、无限细分、局部近似」等动态边界，提前破除学极限时高频认知障碍。
## 前置依赖
- 前置学习：case15 model_scenario
- 后续：note‑C高中直观微积分随笔
## 学习目标
【基础目标】扫清初中数学核心概念漏洞，规避高频易错边界题型。
【前瞻目标】建立边界辨析、趋近思维、严谨性思维。
## 模块细分
1. **代数边界**：除零禁忌、符号陷阱、表达式失效条件、参数取值边界
2. **函数边界**：定义域限制、端点取舍、分段函数边界、变化区间边界
3. **动态边界（微积分重点）**：点无限靠近、分割无限细化、趋近不等于重合、局部近似整体的动态场景辨析

## 核心概念
1. 代数表达式存在生效范围，不是全部数字都可以随便代入。
2. 函数要看定义域，部分点表达式会失效。
3. “无限靠近” ≠ “完全等于”，是极限最重要的思维门槛。

## 可视化绘图要点
1. 示意图：除零失效、函数空心间断点。
2. 示意图：点不断向定点靠近，但不等于该点。
## 教学提示
本案例为note‑B收官，是通往note‑C的认知安检。很多学生学极限、导数踩坑，根源来自初中没有处理好边界、失效条件、趋近不等于相等。
