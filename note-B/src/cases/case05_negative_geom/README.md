# case05 negative_geom 负数与绝对值拓展｜负数运算的几何图景
## 专题简介
不再只停留在单纯数字正负，用**有向线段**理解负数加减法。把加减运算翻译成数轴上点位的移动，引出增量 $\Delta$ 的直观雏形，为后续变化率做铺垫。
## 前置依赖
- 前置学习：case04 coord_walk
- 后续依赖：case06 polynomial_geom
## 学习目标
【基础目标】吃透负数、相反数、绝对值的拓展运算，解决含参、分段、多符号易错题型。
【前瞻目标】掌握**有向线段**几何意义，理解正负代表方向，初步建立增量Δ的直观雏形。
## 核心概念
1. 有向线段：不仅有长度，还带有方向；正代表向右，负代表向左。
2. 加法：数轴上点位向右/向左平移；减法等价于加上相反数。
3. 增量 $\Delta x = x_2 - x_1$：两点之间带方向的变化量。
## 可视化绘图要点
1. 绘制数轴，用彩色箭头表示有向线段。
2. 多帧展示：正数相加、负数相加、减去一个数等价于加相反数。
3. 绘制增量 $\Delta x$ 箭头，区分“长度”和“带符号增量”。
## 教学提示
重点区分：**线段长度永远≥0；有向增量可正可负，代表移动方向**。$\Delta$ 是后续导数变化率的基础符号雏形。
