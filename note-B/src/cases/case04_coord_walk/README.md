# case04 coord_walk 坐标系点行走平移｜平面直角坐标系
## 专题简介
从一维数轴升级到二维平面直角坐标系。观察点的平移、对称，理解坐标参数变化如何带动点位移动，建立二维动态几何基础。
## 前置依赖
- 前置学习：case03 balance_scale、case01 number_line
- 后续依赖：case05 negative_geom
## 学习目标
【基础目标】掌握平面直角坐标系构成、点的坐标表示、点的平移与对称规律。
【前瞻目标】实现一维数轴到二维坐标的思维升级，感知「参数变化带动点位移动」的动态过程，建立动态几何底层认知。
## 核心概念
1. x轴横轴，y轴纵轴，原点O(0,0)，四个象限
2. 点 $P(x,y)$；横坐标左右，纵坐标上下
3. 平移：$x$增减→左右移动；$y$增减→上下移动
4. 对称：关于x轴对称、y轴对称点坐标变换规则
## 可视化绘图要点
1. 绘制完整平面直角坐标系，标注象限
2. 多帧：一个点做左右、上下平移，同步打印新旧坐标
3. 绘制点关于x轴、y轴对称后的点位，对比坐标变化
## 教学提示
重点：坐标数字的改变，直接对应平面上点的位置改变。后续函数图像、割线逼近全部建立在这套动态点位认知之上。
