# case03 balance_scale 天平动画｜等式性质与一元一次方程
## 专题简介
以天平作为具象模型理解等式：两边重量相等代表等式成立。通过天平增、减物体，直观展示等式两条基本性质，过渡到一元一次方程求解。
## 前置依赖
- 前置学习：case02 area_identity
- 后续依赖：case04 coord_walk
## 学习目标
【基础目标】直观理解等式基本性质，熟练求解一元一次方程，掌握方程应用基础思路。
【前瞻目标】区分常量与未知量，理解等量变换的不变性，为后续变量替换、方程约束关系铺垫认知。
## 核心概念
1. 等式性质1：等式两边同时加（减）同一个数，等式仍然成立
2. 等式性质2：等式两边同时乘（除）同一个不为0的数，等式仍然成立
3. 一元一次方程：只含一个未知数，未知数次数为1的等式
## 可视化绘图要点
1. 绘制天平示意图，左右托盘代表等式左右两边
2. 多帧：展示两边同时增加物体、同时拿走物体；同倍数缩放重量
3. 用方块代表未知数x，圆形代表已知常量
## 教学提示
天平核心：**两边必须做完全一样的操作，平衡（等式）才不会被破坏**，建立等量变换不变的思维。
