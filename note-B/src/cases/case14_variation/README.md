# case14 variation 变量与变化关系专题【核心内嵌：离散累积】
## 专题简介
分清常量、自变量、因变量。重点训练**分割—小块累加得到总量**的离散累积思想；用矩形拟合曲线图形做直观演示，不引入积分公式定义，为note‑C黎曼积分做前置铺垫。
## 前置依赖
- 前置学习：case13 stat_prob
- 后续依赖：case15 model_scenario
## 学习目标
【基础目标】区分常量与变量、自变量与因变量，识别生活与数学中的变化关系。
【前瞻目标（积分核心雏形）】掌握「整体分割为无数小块、小块累加得到总量」的逻辑；通过矩形拟合曲线图形，直观理解**面积累积**，不引入积分公式与定义。
## 核心概念
1. 常量：数值固定不变；变量：数值可以发生改变。
2. 自变量：主动发生变化；因变量：跟随自变量而改变。
3. 离散累积：把整体拆成很多小部分，每一小块算出大小，全部相加还原整体总量。
## 可视化绘图要点
1. 简单示例：矩形拆分演示小块累加等于总面积。
2. 演示用若干小矩形去逼近曲线下方图形，小块求和近似总面积。
