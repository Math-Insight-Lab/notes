# case01 Rectangular Approximation 曲边图形矩形无限细分逼近

## 专题简介
本课以**几何面积作为极限启蒙入口**，不先抛出极限符号。通过把曲边梯形不断切分成细小矩形，直观观察：矩形数量越多，所有矩形面积之和越贴近曲线下方真实面积。

## 前置依赖
- 前置学习：note-B 坐标、函数图像、长方形面积
- 后续依赖：case02 Error Convergence

## 学习目标
【基础目标】理解曲边图形不能直接套用简单面积公式；把图形切割成小矩形做近似；矩形细分越多，近似越精准。
【前瞻目标】初步感知"无限细分、无限靠近"的过程，建立极限直觉，不引入严格定义。

## 核心概念
1. 曲边梯形：一边为曲线，其余三边是直线围成图形
2. 矩形近似：把区间切成n等份，每一小条用矩形代替曲边
3. 细分：n增大，矩形宽度变小，整体近似效果变好

## 可视化绘图要点
1. 选取 $f(x)=x^2$，区间 $[0,2]$，绘制曲边梯形
2. 批量生成多帧图片：n=2, n=4, n=8, n=16, n=32
3. 每一帧绘制对应数量的矩形，填充蓝色半透明，叠加黑色原函数曲线
4. 图中标注：矩形总面积、真实面积，直观对比数值差距

## 教学提示
重点：这里暂时不定义极限。只观察现象：**切得越细，近似值越接近真实值**。不使用复杂符号，重在看图感知。

## 输出产物

### 第 1 组：矩形逼近逐步细分（5帧动画组）

**说明：** 以 f(x)=x² 在 [0,2] 上的曲边梯形为例，展示左矩形黎曼和从 n=2 到 n=32 的逐步增加过程。每帧用蓝色半透明矩形覆盖曲线下方，图中标注当前矩形总面积与真实面积（8/3 ≈ 2.67）。所有5帧统一使用**左端点黎曼和矩形法**——每个小区间用左端点高度 f(xi) 构建矩形。

**关键观察（教学要点）：**

- **最左侧矩形高度始终为 0**：f(x)=x² 在 x=0 处 f(0)=0，因此每个帧的最左侧矩形高度为 0（视觉上不可见，与 x 轴重合）。这是左端点法的正常行为——对于单调递增函数，左端点法总是从最低点开始。
- **左矩形法始终低估真实面积**：因为函数单调递增，左端点高度 < 曲线高度，所以矩形总面积 < 真实面积。你可以从标题中的 area 值看到：n=2 时 area=1.0000（远低于 2.6667），n=32 时 area=2.5615（已非常接近）。
- **所有帧都是矩形法**：不存在"前2帧梯形、后3帧矩形"的切换。5帧只是矩形数量从粗到细的递进过程。
- **n 越大逼近越精确**：area 值从 1.0000 逐步收敛到 2.6667。

**包含文件：**

- `frame_00_n2.png`（n=2，area=1.0000，误差最大）
- `frame_01_n4.png`（n=4，area=1.7500）
- `frame_02_n8.png`（n=8，area=2.2500）
- `frame_03_n16.png`（n=16，area=2.5000）
- `frame_04_n32.png`（n=32，area=2.5615，已非常接近真实值 2.6667）

**关系/意义：** 这5帧构成一组序列：同一图形、同一函数、同一方法（左矩形），仅矩形数量递增。学生可以按顺序观察，理解"无限细分"不是抽象概念，而是肉眼可见的逼近过程。

**常见误解澄清：**

- 之前有学生误以为 `convergence_series_4panel.png.png` 属于 case01。该文件实际上是 case11 的产出（f(x)=sin(x)，四宫格对比图），不应出现在 case01 的 assets 目录中。
- 如果看到 case11 的曲线方向与 case01 的 frame 不同，那是因为它们使用完全不同的函数（x² vs sin(x)），不是"方向反转"。
